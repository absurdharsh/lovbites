## ✨ Features Built

1. **Brand Preloader / Loading Animation**:
   - Uses the circular brand logo (`images/lavbites1.jpg`).
   - SVG circular border with real-time percentage progress (`0%` → `100%`).
   - Triple radiating heartbeat pulse rings.
   - Dynamic rotating culinary preparation messages.
   - Floating particle hearts and smooth curtain reveal transition.
   - "Skip Intro" option and footer "Replay Intro Animation" button.

2. **Scraped & Verified Profile Info (`@lovbitescafe`)**:
   - **Tagline**: *"Fresh Food • Warm Hospitality • Memorable Moments"* & *"Dine • Celebrate • Connect"*.
   - **Location**: Ground Floor, Om Sai Plaza, Police Line Road, Near HDFC Bank, CMPF Colony, Hirapur, Dhanbad – 826007.
   - **Hours**: 8:00 AM – 11:00 PM Daily (8 AM Onwards).
   - **Contact**: +91 82888 47444 / Instagram: [@lovbitescafe](https://www.instagram.com/lovbitescafe/).
   - **Food delivery**: Swiggy & Zomato integration.

3. **Interactive Menu with Tray & WhatsApp Ordering**:
   - Categories: Royal Biryanis, Pizzas & Pastas, Burgers & Fries, Momos & Starters, Desserts & Shakes, Artisan Coffee & Coolers.
   - Veg / Non-veg badges, pricing, and ingredients.
   - Floating "My Order Tray" drawer with quantity adjustment and direct WhatsApp order generation.

4. **Table & Celebration Booking**:
   - Interactive booking form for romantic dates, birthdays, anniversaries, and family dinners with automated WhatsApp booking requests.

5. **Instagram Reels & Moments Showcase**:

## 🚀 How to Run Locally

To preview the website in your browser:

```bash
# Using Python built-in HTTP server:
python3 -m http.server 8000
```

Then open `http://localhost:8000` in your web browser.
